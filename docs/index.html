Aether

A modern, cross-platform Multi-Client Protocol (MCP) client for Large Language Models. Built with Tauri and Next.js for native performance and beautiful user experience.

📥 Download Now ⭐ Star on GitHub

Why Choose Aether?

🚀

Cross-Platform

Runs natively on Windows, macOS, and Linux with a single codebase. Built with Tauri for optimal performance.

🔒

Secure by Design

API keys stored in OS keyring. No network calls from frontend. All data stays on your device.

🤖

Multi-Provider

Support for OpenAI, local LLMs (Ollama, LM Studio), and custom endpoints. Switch between providers seamlessly.

💬

Real-time Streaming

Live chat responses with typing indicators. See AI responses as they're generated, not after completion.

📚

Conversation Management

Full CRUD operations for conversations. Rename, delete, and organize your chats with ease.

🎨

Beautiful UI

Modern design with shadcn/ui components. Dark/light themes, smooth animations, and responsive layout.
